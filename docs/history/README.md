# 1995 年一手史料：《A'can 特輯》

本目錄的七份文件不是本庫寫的，是從**《電視遊樂雜誌》專藏**（私有的台灣電視遊樂器
史料庫）複製過來的史文。它們的共同一手來源是同一冊出版品：

| 項目 | 內容 |
|---|---|
| 書名 | 《A'can 特輯》，「電玩玩味叢書」第 016 號 |
| 出版 | 尖端出版有限公司，1995 年 10 月初版 |
| 登記 | 新聞局登記臺業字第 2680 號（出版事業登記）|
| 定價 | 160 元 |
| 篇幅 | 掃描 108 頁 |
| 自述 | 封面「全球獨家獨步・第一本本土電玩主機綜合情報專刊」；編者的話稱「A'can 特輯試刊號」，封面標「創刊號」，兩處並陳 |

## 這批材料為什麼重要

本庫其餘文件的證據來自模擬器、BIOS dump 與晶片反編譯，時間點都在 2020 年代。
這一冊是**主機發售當月、由開發公司提供資料的出版品**，補的是另一種東西：
開發代號、公司分工、開發期長度、當時的規格宣稱，以及軟體廠商自己的說法。

技術結論與這些史料的逐項對照見 [../console-history.md](../console-history.md)。

## 證據性質

⚠ 這一冊的版權頁印「**本書圖文皆轉載於敦煌科技及各軟體廠商**」。也就是說，
它對 A'can 硬體的描述**來源是開發公司提供的資料，不是雜誌的獨立測試**。
以本庫的分級，這批材料是 **(c) 二手報導**，而且是帶有廠商立場的二手報導——
比維基百科的來源近，但仍不是量測。當它與 (a) 級的實測結果衝突時以實測為準。

各檔案內文已逐條標明哪些是受訪者說法、哪些是雜誌轉述、哪些經原圖核實。
引用時請保留這層區分。

## 不在這裡的東西

- **雜誌內文的 OCR 全文與掃描圖**：那是尖端出版與敦煌科技的著作，留在私有專藏，
  不進本庫也不上公開站台。這裡只有史文與其中為佐證所需的短引文。
- **「掃描 p.N」的頁碼**指私有專藏的掃描頁序，本庫沒有對應圖檔；
  它保留在文中是為了讓引用可回溯，不是可點的連結。
